# winzoomer

https://github.com/tsoding/boomer 的一个可能的 windows 版本

## 环境&工具
- mingw-w64	此程序使用 w64devkit 2.1.0
- freetype 2.10.0	可以在markdown 内直接设置不包含freetype

## 控制方式
| 功能 | 快捷键 |
| --- | --- |
|退出|<kbd>Esc</kbd>|
|手电筒|<kbd>F</kbd>|
|缩放手电筒(包括画面)|<kbd>Ctrl</kbd> + <kbd>滚轮</kbd>  |
|缩放手电筒|<kbd>Shift</kbd> + <kbd>滚轮</kbd> |
|重置|<kbd>R</kbd>|
| 实时画面|<kbd>U</kbd>|
